# 文星盲文显示器通信协议

本文档描述本插件与文星盲文显示器之间的 USB 通信协议。设备通过 WinUSB 驱动访问，主机与设备之间以 64 字节定长数据包进行通信，数据包首字节为命令字。按键通过轮询机制上报。

## 1. 基本信息

### 1.1 协议类型与接口

- 协议类型：USB 通信协议
- 驱动：WinUSB
- USB VID：`0x04D8`
- USB PID：`0x0053`
- 设备接口 GUID：`{58D07210-27C1-11DD-BD0B-0800200C9A66}`
- 数据端点：输出 `0x01`，输入 `0x81`
- 单包长度： 定长 64 字节

### 1.2 整体技术架构概述

插件运行于主机侧，通过 WinUSB 以**独占**方式打开文星盲文显示器。插件首先按接口 GUID 枚举设备，仅保留设备路径中包含硬件 ID `usb#vid_04d8&pid_0053` 的设备。

通信采用 64 字节定长包，首字节为命令字。当前协议包含显示盲文和查询按键两种指令。

## 2. 数据包结构与指令

### 2.1 数据包结构

所有收发数据均为 64 字节定长包，第 1 字节（字节 0）为命令字。

- 显示盲文：命令值 `0x80`，方向为主机 → 设备，含义为刷新 40 方盲文。设备无回复包。
- 查询按键：命令值 `0x81`，方向为主机 ↔ 设备，含义为请求/返回当前按键。设备会返回一个数据包。

### 2.2 显示盲文（`0x80`）

主机发送该命令，设备不回复。

```text
字节 0       : 0x80
字节 1..40   : 40 个盲文单元，每单元 1 字节（8 个点位）
字节 41..63  : 0x00 填充
```

盲文单元按屏幕从左到右排列。

### 2.3 查询按键（`0x81`）

该命令为一问一答模式，必须成对调用：

1. 主机发送 64 字节包，字节 0 = `0x81`，其余为 0。
2. 设备返回 64 字节包。

返回包格式：

```text
字节 0 : 0x81（命令回显）
字节 1 : 当前按下的按键 ID；0xFF 表示没有按键按下
其余   : 保留
```

设备返回的第 1 字节不是 `0x81` 时，视为通信失败。

### 2.4 按键 ID

- ID 1–40：第 1–40 方的路由光标键。
- ID 41：上一行。
- ID 42：上一屏。
- ID 43：Tab。
- ID 44：下一行。
- ID 45：下一屏。
- ID 46：回车。
- ID 0xFF 无任何按键被按下。

## 3. 连接与错误处理流程

### 3.1 连接与握手

1. 枚举设备，并按上述 VID/PID 过滤；插件按接口 GUID 枚举设备，仅保留路径中包含硬件 ID `usb#vid_04d8&pid_0053` 的设备。
2. 打开设备，初始化 WinUSB。
3. 发送一次“查询按键”包并读取回复。
4. 回复包首字节为 `0x81` 即握手成功，否则放弃该设备。

连接失败时，释放句柄后重试下一个设备。

### 3.2 错误处理

以下 Win32 错误处理方式为推荐做法，具体返回值与恢复策略可由实现和上层逻辑调整：

- 若收发返回 Win32 错误，建议将本次操作视为失败；显示盲文可返回 `false`，按键查询可返回 `-1`。
- 若收到非预期命令字，视为通信失败。
- 通信失败后，由上层决定是否重新连接。

## 4. 按键轮询设计

- 推荐插件每 **50 ms** 发送一次查询按键命令；该间隔可按实际负载和响应要求调整。
- 设备只回报“当前按下”的键，不产生按键事件。其中，包含特别值表示无任何按键被按下。
- 按键具体的处理逻辑可以使用一个状态机来管理，上层应用可实现按下、抬起、长按、连击、双击、多击、点击等各种逻辑。
- 轮询处理的时候，注意有发有接，保持设备状态可控，防止垃圾值破坏协议通讯。
